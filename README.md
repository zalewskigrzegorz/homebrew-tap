# Greg's Homebrew tap

Casks I ship myself. Right now that is [Gzyms](https://gzyms.dev), a menu bar for macOS.

```sh
brew install zalewskigrzegorz/tap/gzyms
```

Needs macOS 26 or newer. `brew upgrade gzyms` updates it, and the in-app updater stays off. You can turn it on in Settings → About, but then brew and the app can both update Gzyms, which can break an update.
