# Greg's Homebrew tap

Casks I ship myself.

**`gzyms`**: a status bar for macOS developers drowning in notifications. Site at [gzyms.dev](https://gzyms.dev), code in [zalewskigrzegorz/gzyms](https://github.com/zalewskigrzegorz/gzyms).

## Install

```sh
brew install zalewskigrzegorz/tap/gzyms
```

## Upgrade

```sh
brew upgrade gzyms
```

Brew updates Gzyms and the in-app updater stays off. If you turn it on in Settings → About, brew and the app can both update the same copy, and that can break an update.
